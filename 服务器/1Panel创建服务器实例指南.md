## 二、第一步：创建云服务器实例

进入云服务商控制台（如腾讯云轻量应用服务器 / CVM、阿里云 ECS、华为云 ECS 等），点击 **"创建实例"** 或 **"新建"** 按钮，进入实例配置页面。

### 2.1 关键配置项

| 配置项 | 推荐设置 | 说明 |
| --- | --- | --- |
| **镜像** | 公共镜像 → **Ubuntu 24.04 LTS**（或 22.04） | 1Panel 对 Ubuntu 支持完善，社区文档最多 |
| **实例规格** | 2 vCPU / 2GB 内存起步 | 1Panel 官方最低 1 核 1G，但跑应用建议 2 核 2G 起步 |
| **存储** | 系统盘 40GB SSD + 数据盘视情况 | 1Panel 默认安装到 `/opt`，建议独立数据盘 |
| **公网带宽** | 按量计费 3–5 Mbps 即可 | 主要用于拉镜像和远程 SSH |
| **登录凭证** | **密码**（新手友好）或 SSH 密钥 | 1Panel 安装脚本会要求 root 权限 |
| **登录名** | `root` | 与图片一致，便于直接安装 1Panel |
| **防火墙** | 放通 22（SSH）、80/443（Web）、1Panel 端口 | 安装完成后会提示端口，按需放通 |

> 💡 **镜像选择说明**  
> 公共镜像、自定义镜像、共享镜像、市场镜像的区别：
> - **公共镜像**：云厂商官方维护，纯净、安全、推荐生产环境使用
> - **自定义镜像**：基于已有实例打包，适合批量部署
> - **共享镜像**：其他用户主动共享给你
> - **市场镜像**：预装应用（如已集成 1Panel 的镜像），开箱即用

### 2.2 确认下单

核对配置后选择购买时长，提交订单，等待实例进入 **"运行中"** 状态，记录下：
- ✅ **实例 ID**（如 `i-yetut1x8u8nu262j1fij`）
- ✅ **公网 IP**
- ✅ **内网 IP**（如 `192.168.181.209`）
- ✅ **初始 root 密码**（控制台发送的短信或邮件）

## 三、第二步：SSH 远程登录服务器实例

实例创建完成后，打开云控制台的 **"远程登录"** 或使用本地终端 SSH 客户端连接。

### 3.1 控制台远程登录（推荐新手）

在实例列表点击 **"登录"** → **"立即登录"**，弹出远程登录对话框，按图示填写：

| 字段 | 填写内容 |
| --- | --- |
| **实例 ID** | 自动填充，如 `i-yetut1x8u8nu262j1fij` |
| **网络连接** | 选择 **私网**（控制台到实例的内网）或 **公网**（外部访问） |
| **连接协议** | 终端连接（SSH） |
| **端口** | `22` |
| **用户名** | `root` |
| **认证方式** | 密码认证 / 密钥认证 二选一 |
| **登录密码** | 创建实例时设置的 root 密码 |
| **快捷登录** | ✅ 勾选"保存登录信息与登录凭证"，下次免输 |

> ⚠️ 忘记密码？控制台提供 **"重置密码"** 入口，重置后需重启实例生效。

### 3.2 本地终端 SSH 登录

如果你已经下载了密钥或在本地知道密码，可以直接：

```bash
# 密码登录
ssh root@<公网IP>

# 密钥登录
ssh -i ~/path/to/private_key.pem root@<公网IP>
```

### 3.3 连接排错

遇到连接失败时：
1. 使用控制台提供的 **"实例诊断工具"** 一键检测
2. 检查安全组 / 防火墙是否放通 22 端口
3. 确认密码或密钥正确
4. 确认实例处于 **"运行中"** 状态

## 四、第三步：在线安装 1Panel

1Panel 提供两种安装方式：**交互式安装**（推荐新手）和 **非交互安装**（适合自动化）。

### 4.1 准备工作

SSH 登录到服务器后，先更新系统（以 Ubuntu 为例）：

```bash
apt update && apt upgrade -y
```

### 4.2 方式一：交互式安装（推荐）

在 SSH 终端执行 1Panel 官方一键安装脚本：

```bash
bash -c "$(curl -sSL https://resource.fit2cloud.com/1panel/package/v2/quick_start.sh)"
```

执行后脚本会引导你逐步设置：

```
? 设置1Panel安装目录（默认为/opt）：直接回车
? 设置1Panel端口（默认为38943）：建议自定义，如 12345
? 设置1Panel面板用户：例如 admin
? 设置1Panel面板密码：输入强密码
? 是否开启面板SSL：建议开启（生产环境）
```

安装过程会自动完成：
- 下载 1Panel 核心组件
- 安装 Docker 依赖（1Panel 内部用 Docker 管理应用）
- 初始化数据库
- 启动 1Panel 服务

最终输出示例：

```
[1Panel Log]: 1Panel 服务启动成功
面板访问地址:  https://<服务器IP>:12345
面板用户名:    admin
面板密码:      ********
```

> 🔐 **务必记下输出中的面板地址、用户名和密码！** 这是登录 1Panel Web 面板的唯一凭证。

### 4.3 方式二：非交互安装（自动化场景）

适合批量部署、CI/CD、初始化脚本等场景，通过环境变量预置参数：

```bash
export PANEL_BASE_DIR=/opt/1panel
export PANEL_PORT=12345
export PANEL_USER=admin
export PANEL_PASSWORD=<强密码>
export PANEL_SSL=true

bash -c "$(curl -sSL https://resource.fit2cloud.com/1panel/package/v2/quick_start.sh)"
```

### 4.4 安装后必做事项

1. **云控制台安全组放通面板端口**（如 12345），否则外网无法访问
2. **绑定域名**（可选）：在 1Panel → 网站 → 域名管理 配置
3. **配置防火墙**：1Panel 自带 `ufw` / `firewalld` 规则管理

## 五、第四步：登录 1Panel 面板

1. 浏览器打开安装完成后输出的地址，如 `https://<服务器IP>:12345`
2. 首次访问会提示不安全证书（自签证书），点击 **"高级" → "继续前往"** 即可
3. 输入用户名 `admin` 和安装时设置的密码登录

进入 1Panel 后，建议立即完成：

| 任务 | 路径 |
| --- | --- |
| 修改默认密码 | 面板设置 → 账户安全 |
| 备份策略 | 计划任务 → 创建快照/备份 |
| 安装应用 | 应用商店 → 搜索 WordPress / Halo / Nginx 等一键部署 |
| 创建网站 | 网站 → 添加站点 |
| 数据库管理 | 数据库 → 添加 MySQL/PostgreSQL/Redis |

## 六、常见问题（FAQ）

**Q1：安装脚本执行失败，提示 `curl: command not found`？**  
A：先安装 curl：`apt install -y curl`（Debian/Ubuntu）或 `yum install -y curl`（CentOS）。

**Q2：忘记 1Panel 面板密码怎么办？**  
A：SSH 登录服务器，执行 `1pctl user update` 命令可重置密码，详见 [官方文档](https://1panel.cn/docs/v2/installation/online_installation/)。

**Q3：服务器只有内网 IP，怎么访问 1Panel？**  
A：通过云控制台的"远程登录"建立隧道，或使用 SSH 端口转发：
```bash
ssh -L 12345:localhost:12345 root@<服务器IP>
# 然后浏览器访问 http://localhost:12345
```

**Q4：1Panel 和宝塔面板（BT Panel）能同时装吗？**  
A：不建议，会造成 80/443 端口冲突和资源争抢，二选一即可。

**Q5：Ubuntu 还是 CentOS 更好？**  
A：1Panel 团队主推 Ubuntu，Docker 兼容性最好；CentOS Stream 8/9 也完全支持。
