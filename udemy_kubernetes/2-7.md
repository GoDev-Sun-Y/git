# Kubernetes 基础命令整理

## 一、核心命令一览

| 命令 | 中文含义 | 主要作用 | 常用输出内容 |
| :--- | :--- | :--- | :--- |
| `kubectl run <名字>` | 运行/创建 | 快速启动一个 Pod | Pod 名称、状态、镜像 |
| `kubectl cluster-info` | 集群信息 | 查看 API 地址、集群状态 | Master 地址、DNS 地址 |
| `kubectl get nodes` | 获取节点 | 查看集群中有哪些机器 | 节点名称、健康状态 (Ready) |

---

## 二、各命令详解

### 1️⃣ `kubectl run hello-minikube`

- **含义**：创建并运行一个新的 Pod
- **详解**：
  - `run`：告诉 kubectl 我要启动一个新的应用实例
  - `hello-minikube`：你给这个 Pod 起的名字
  - **默认行为**：如果不加额外参数，它会基于一个默认的镜像（通常是 nginx 或 pause 容器）启动一个单容器 Pod
- **对应场景**：相当于你告诉集群：“给我起个叫 `hello-minikube` 的容器，跑起来！”

### 2️⃣ `kubectl cluster-info`

- **含义**：查看集群的信息
- **详解**：
  - 显示 Kubernetes 集群的核心组件地址，比如 API Server 的地址、KubeDNS 的地址等
  - 告诉你当前 `kubectl` 连接的是哪个集群，以及集群的控制平面（Master）在哪里
- **对应场景**：相当于你刚连上一个新服务器，先输入 `ipconfig` 或 `hostname` 看看自己连到哪了

### 3️⃣ `kubectl get nodes`

- **含义**：获取（列出）所有的节点（Node）
- **详解**：
  - `get`：获取资源
  - `nodes`：资源类型是节点（即运行 Pod 的机器）
  - 执行后会看到类似 `NAME`、`STATUS`、`ROLES` 等信息，告诉你集群里有几台机器，是否在正常运行（Ready）
- **对应场景**：相当于你在管理一个机房，先敲命令看看手底下有几台机器，它们是不是都在线

---
## 三、实用小技巧

- **查看详细信息**：在命令后加上 `-o wide` 参数，可以显示更多信息，例如：
```bash
kubectl get nodes -o wide
```
这样可以查看每个节点具体的 IP 地址、操作系统版本、内核版本等。

- **持续监控**：加上 `-w` 参数可以实时监听资源变化：

```bash
kubectl get pods -w
```
