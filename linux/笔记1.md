# Linux 基础命令语法总结（含常用选项）

## 一、环境与基础操作

| 命令 | 说明 | 补充 |
|------|------|------|
| 安装虚拟机 | 搭建 Linux 运行环境的基础步骤 | 通常使用 VMware 或 VirtualBox |
| 为其安装系统 | 在虚拟机中安装 Linux 发行版 | 如 CentOS, Ubuntu 等 |
| 使用 finalShell 操作 | 使用第三方终端工具连接服务器 | 类似于 Xshell，支持文件传输和命令行操作 |
| `ls` | 列出目录内容 | 见下方详细参数 |
| `cd` | 切换工作目录 | 如 `cd /home` |
| `pwd` | 显示当前工作目录路径 | Print Working Directory |

### `ls` 常用选项

| 选项 | 说明 | 示例 |
|------|------|------|
| `-a` | 显示所有文件，包括隐藏文件（以`.`开头） | `ls -a` |
| `-l` | 以长格式显示详细信息（权限、大小、时间等） | `ls -l` |
| `-h` | 与`-l`一起使用，以人类可读方式显示大小（K、M、G） | `ls -lh` |
| `-R` | 递归显示子目录内容 | `ls -R` |
| `-t` | 按修改时间排序（最新在前） | `ls -lt` |
| `-S` | 按文件大小排序 | `ls -lS` |
| `-d` | 只显示目录本身，不列出其内容 | `ls -d */` |

## 二、文件与目录管理

### `mkdir` — 创建目录

| 选项 | 说明 | 示例 |
|------|------|------|
| `-p` | 递归创建多级目录 | `mkdir -p a/b/c` |
| `-v` | 显示创建过程 | `mkdir -v newdir` |

### `touch` — 创建空文件或更新文件时间戳

| 选项 | 说明 | 示例 |
|------|------|------|
| 无参 | 创建新文件 | `touch file.txt` |
| `-c` | 不创建文件，仅更新时间戳 | `touch -c exist.txt` |

### `cat` — 查看文件内容

| 选项 | 说明 | 示例 |
|------|------|------|
| `-n` | 显示行号 | `cat -n file.txt` |
| `-b` | 显示行号（忽略空白行） | `cat -b file.txt` |
| `-E` | 在每行末尾显示`$`符号 | `cat -E file.txt` |

### `more` — 分页查看文件

| 操作 | 说明 |
|------|------|
| 空格键 | 下一页 |
| Enter | 下一行 |
| q | 退出 |
| `/pattern` | 搜索模式 |

### `cp` — 复制文件或目录

| 选项 | 说明 | 示例 |
|------|------|------|
| `-r` | 递归复制目录 | `cp -r dir1 dir2` |
| `-i` | 覆盖前提示确认 | `cp -i src dest` |
| `-u` | 仅当源文件比目标文件新时才复制 | `cp -u src dest` |
| `-v` | 显示复制过程 | `cp -v src dest` |
| `-p` | 保留原文件属性（权限、时间戳） | `cp -p src dest` |

### `mv` — 移动或重命名

| 选项 | 说明 | 示例 |
|------|------|------|
| `-i` | 覆盖前提示 | `mv -i old new` |
| `-u` | 仅当源文件更新时才移动 | `mv -u src dest` |
| `-v` | 显示移动过程 | `mv -v file dir/` |

### `rm` — 删除文件或目录

| 选项 | 说明 | 示例 |
|------|------|------|
| `-r` | 递归删除目录及其内容 | `rm -r dir` |
| `-f` | 强制删除，不提示 | `rm -f file` |
| `-i` | 删除前逐一确认 | `rm -i file` |
| `-rf` | 最常用的组合：递归强制删除 | `rm -rf dir` |

## 三、查找与过滤

### `which` — 查找命令的可执行文件路径

| 选项 | 说明 | 示例 |
|------|------|------|
| `-a` | 显示所有匹配路径（非仅第一个） | `which -a python` |

### `find` — 查找文件

| 常用条件 | 说明 | 示例 |
|----------|------|------|
| `-name "*.txt"` | 按文件名通配符查找 | `find / -name "*.log"` |
| `-type f` | 只找普通文件 | `find . -type f` |
| `-type d` | 只找目录 | `find . -type d` |
| `-size +100M` | 查找大于100MB的文件 | `find / -size +1G` |
| `-mtime -7` | 7天内修改过的文件 | `find . -mtime -1` |
| `-exec {} \;` | 对找到的结果执行命令 | `find . -name "*.tmp" -exec rm {} \;` |

### `grep` — 文本搜索过滤

| 选项 | 说明 | 示例 |
|------|------|------|
| `-i` | 忽略大小写 | `grep -i "error" log.txt` |
| `-r` | 递归搜索目录下所有文件 | `grep -r "TODO" ./src` |
| `-n` | 显示匹配行号 | `grep -n "main" main.c` |
| `-v` | 反向匹配（显示不包含的行） | `grep -v "^#" config.conf` |
| `-c` | 只统计匹配行数 | `grep -c "failed" log.txt` |
| `-E` | 扩展正则表达式 | `grep -E "error|fail" log.txt` |
| `--color` | 高亮显示匹配内容 | `grep --color "key" file` |

### `wc` — 统计

| 选项 | 说明 | 示例 |
|------|------|------|
| `-l` | 统计行数 | `wc -l file.txt` |
| `-w` | 统计单词数 | `wc -w file.txt` |
| `-c` | 统计字节数 | `wc -c file.txt` |
| `-m` | 统计字符数 | `wc -m file.txt` |

### `echo` — 输出字符串或变量值

| 选项 | 说明 | 示例 |
|------|------|------|
| `-e` | 启用转义字符（如\n换行） | `echo -e "line1\nline2"` |
| `-n` | 不输出尾随换行符 | `echo -n "no newline"` |

### `tail` — 查看文件尾部内容

| 选项 | 说明 | 示例 |
|------|------|------|
| `-n N` | 显示最后N行 | `tail -n 20 file.log` |
| `-f` | 实时跟踪文件追加内容（监控日志） | `tail -f app.log` |
| `-F` | 类似`-f`，但会检测文件是否被重新创建 | `tail -F /var/log/syslog` |

## 四、权限与用户管理

### 1. 编辑器
- `vi` / `vim`：文本编辑器，常用模式：
  - 普通模式：`Esc`
  - 插入模式：`i`, `a`, `o`
  - 命令行模式：`:wq`（保存退出）, `:q!`（强制退出）, `:set nu`（显示行号）

### 2. 用户与组命令

#### `groupadd` / `groupdel`

| 命令 | 选项 | 说明 | 示例 |
|------|------|------|------|
| `groupadd` | `-g GID` | 指定组ID | `groupadd -g 2000 devops` |
| `groupdel` | 无 | 删除组 | `groupdel oldgroup` |

#### `useradd` / `userdel`

| 命令 | 选项 | 说明 | 示例 |
|------|------|------|------|
| `useradd` | `-m` | 自动创建家目录 | `useradd -m tom` |
| | `-g` | 指定主组 | `useradd -g developers bob` |
| | `-s` | 指定登录shell | `useradd -s /bin/bash alice` |
| `userdel` | `-r` | 同时删除家目录和邮件池 | `userdel -r tom` |

#### `usermod` — 修改用户属性

| 选项 | 说明 | 示例 |
|------|------|------|
| `-aG` | 将用户添加到附加组（追加） | `usermod -aG sudo bob` |
| `-l` | 更改用户名 | `usermod -l newname oldname` |
| `-d` | 更改家目录 | `usermod -d /new/home user` |

#### `id` — 查看用户身份信息

| 选项 | 说明 | 示例 |
|------|------|------|
| 无参 | 显示当前用户UID/GID/组 | `id` |
| `username` | 显示指定用户信息 | `id root` |
| `-u` | 仅显示UID | `id -u` |
| `-g` | 仅显示GID | `id -g` |

#### `getent` — 从系统数据库查询

| 用法 | 说明 | 示例 |
|------|------|------|
| `getent passwd` | 列出所有用户（同`cat /etc/passwd`） | `getent passwd` |
| `getent group` | 列出所有组 | `getent group` |
| `getent shadow` | 列出用户密码信息（需root） | `sudo getent shadow` |

#### `su` / `sudo` — 切换用户与提权

| 命令 | 说明 | 示例 |
|------|------|------|
| `su - username` | 切换到指定用户（加载环境变量） | `su - root` |
| `sudo command` | 以root权限执行单条命令 | `sudo apt update` |
| `sudo -i` | 进入交互式root shell | `sudo -i` |
| `sudo -u user command` | 以指定用户身份执行命令 | `sudo -u www-data ls /var/www` |

## 五、实用技巧补充

- **通配符**：`*` 匹配任意多个字符，`?` 匹配单个字符，`[abc]` 匹配方括号内任一字符。
- **管道 `|`**：将前一个命令的输出作为后一个命令的输入，例如 `ls -l | grep "txt"`。
- **重定向**：`>` 覆盖写入，`>>` 追加写入，`<` 读取文件作为输入。
- **快捷键**：`Ctrl+C` 终止当前命令，`Ctrl+Z` 暂停任务，`Tab` 自动补全。
